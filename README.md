# Hakathon-2-Todo-App

This repository contains the complete journey of building a Todo Application through multiple phases as part of a Hakathon challenge. Each phase represents a different level of complexity and technology stack advancement.

## Repository Structure

### Phase-1-Todo-App
- **Description**: Basic Todo application implementation
- **Technology**: Python
- **Features**: Simple command-line interface for managing tasks

### Phase-2-Todo-App
- **Description**: Enhanced Todo application with backend and frontend separation
- **Technology**: Backend and Frontend components
- **Features**: More advanced functionality with separate service layers

- **Description**: Advanced Todo application with cloud deployment capabilities
- **Technology**: Kubernetes, Helm, Dapr, Vercel
- **Features**: 
  - Containerized deployment
  - Cloud-native architecture
  - Authentication integration
  - API connectivity

## Project Overview

This Hakathon project showcases the evolution of a simple Todo application from a basic Python script to a sophisticated, cloud-ready application using modern development practices and deployment strategies.

## Technologies Used Across Phases

- Python
- Web Frameworks
- Kubernetes
- Helm Charts
- Dapr (Distributed Application Runtime)
- Vercel for frontend deployment
- Authentication services
- API integrations
