# Phase-1 Todo App

This repository contains **Phase-1 Todo Application** developed as part of **Hackathon-2**.

The main goal of Phase-1 is to build a **basic and reliable Todo system** focusing on core logic, clean structure, and correct behavior before moving to advanced features.

---

## 🎯 Project Objective

- Understand problem-solving using programming fundamentals  
- Implement task management logic step-by-step  
- Follow clean and readable code structure  
- Prepare a strong base for upcoming phases

---

## ✨ Features (Phase-1)

- Add new todo tasks  
- View all tasks  
- Update existing tasks  
- Delete tasks  
- Simple flow without unnecessary complexity

---

## 🧰 Tech Stack

- **Programming Language:** Python  
- **Type:** Console-based Application  
- **Focus:** Logic, structure, and correctness
